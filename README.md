# Kasir Toko

Website kasir toko dibuat dengan Laravel 11, MySQL, dan Bootstrap 5.

## Fitur
- Register & Login (password terenkripsi)
- CRUD Barang (per akun)
- Penjualan (banyak barang, hitung kembalian otomatis)
- Riwayat Penjualan
- Logout

## Cara Menjalankan
1. Clone repository ini
2. `composer install`
3. Salin `.env.example` menjadi `.env`
4. `php artisan key:generate`
5. Buat database `kasir_toko`, lalu import file `database/kasir_toko.sql`
6. `php artisan serve`
